# Duo: исследование исходных анимаций

Дата: 29 сентября 2026

## Что найдено и проверено

Скачаны 12 настоящих анимаций совы Duo в Lottie JSON с публичного CDN текущего сайта Duolingo. Пути обнаружены в JS-бандле, загружаемом официальной стартовой страницей `https://www.duolingo.com/`. Не использовались фанатские перерисовки. Файлы нужны только для визуального исследования, не для включения в продукт BotAI.

Локальная воспроизводимая галерея: `artifacts/lemur/references/duo/index.html`. Сервер исследования: `http://localhost:4178/`. Точные исходные URL, размеры и длительности: `artifacts/lemur/references/duo/manifest.json`.

Визуальная проверка: галерея открыта в браузере, 12 файлов успешно рисуют сову, изменения фаз видны между наблюдениями. Просмотрены вращение, прыжок, взмахи, чтение, помпоны, музыка, трюк с кристаллом. Это пригодный reference corpus, но не полная коллекция всех когда-либо созданных анимаций Duolingo. Не найдены подтверждённые самостоятельные оригиналы плача и приветственного waving; пользовательские скриншоты этих поз остаются референсом формы, а не доказательством тайминга.

## Что следует перенести в лемура

Наблюдения исследователя, а не официальные численные нормативы:

1. Лицо читается в каждом ключевом кадре: глаза меняют направление до/вместе с намерением тела, закрытые радостные веки имеют чистый силуэт
2. Один главный жест на сцену. Хвост/уши/ступни должны подкреплять жест, а не постоянно двигаться независимо
3. Различимые стадии: ожидание → подготовка → главный акцент → мягкая остановка → пауза. Непрерывный синусоидальный bounce всех частей не повторяет это качество
4. В прыжке есть направление и вес: вниз перед толчком, растяжение при подъёме, сжатие при приземлении. Тень остаётся привязана к земле
5. Поворот Duo меняет рисунок лица и перекрытия частей; это не простое вращение плоской картинки. Лемуру необходимы отдельные front и profile poses для правой ходьбы
6. Показ результата содержит спокойное удержание. В `Score-increase.gif` активная серия занимает примерно первые 3 секунды, последние 2+ секунды позволяют прочитать результат
7. Точно одинаковый character rig во всех сценах важнее числа сцен. Маска, число колец хвоста, тёмный кончик и пропорции глаз должны оставаться постоянными

## Технология: GIF не является универсальным ответом

Текущий официальный web bundle одновременно содержит Lottie JSON и Rive `.riv`. Скачанные pathCharacters Duo действительно Lottie, все 60 fps; splash-анимации в том же бандле встречаются с 30 fps. Следовательно нельзя утверждать «Duolingo использует только Rive» или «GIF - их production стандарт».

Duolingo описывает Rive как компактный runtime с программно управляемыми состояниями и переходами; вместо отправки видео он позволяет реагировать на действия пользователя. Это статья о world characters, не доказательство формата каждого Duo asset. [Duolingo: How we animate world characters](https://blog.duolingo.com/world-character-visemes/)

Интервью команды подтверждает workflow: animator timelines, creative technologist state machine, спецификация inputs и передача интерактивного файла инженерам. [Rive: Duolingo creative technologists](https://framer.rive.app/blog/creative-technologists-duolingo-s-solution-to-the-designer-to-developer-handoff)

Для этой самостоятельной поставки: единый векторный rig + интерактивный browser preview + видео/GIF для просмотра. Выбор production Rive/Lottie/SVG делается отдельно при интеграции и не оправдывает установку новой зависимости сейчас

## Источники

- [Официальная текущая страница](https://www.duolingo.com/): ссылки CDN исходников в manifest.json
- [Duolingo Score](https://blog.duolingo.com/duolingo-score/): официальный GIF прыжков и результата
- [Building character](https://blog.duolingo.com/building-character/): геометрическая конструкция, крупные глаза, собственный силуэт, отделённые ступни; применение rewards в уроках
- [How to draw Duo](https://blog.duolingo.com/steps-for-drawing-duo/): построение узнаваемого лица из простых форм
- [Duo voice and motion guidelines](https://design.duolingo.com/writing/duo): страница доступна в поисковом индексе, прямое обращение в этой сессии переадресует в design hub; старые guidelines не надо выдавать за исчерпывающую норму актуальных анимаций

## Границы качества

Этот документ не заявляет полного архива всех Duo. Галерея содержит 12 подтверждённых анимаций только совы, все воспроизводятся. Не следует выдавать фанатские Rive remakes за оригиналы. Референсы не включать в публичный пакет маскота
