Команда: `node --test scripts/test-work-3-behavior.mjs`

## Зелёный этап

Те же **28 тестов прошли** после реализации.

- Готовый ответ: знаковое целое или конечная десятичная запись с точкой/запятой
- Черновик: пустота, минус, незавершённая дробь остаются редактируемыми, но не считаются ответом
- Неверная вставка отклоняется целиком; данные не превращаются незаметно в другое число
- Одна чистая валидация используется вводом, заполненностью и проверкой результата; старые неверные данные не засчитываются
- Нормализация сравнивает десятичные строки без округления JavaScript Number
- Первый клик вызывает переход, второй в том же ожидании блокируется
- Создание сессии убрано из каталога; существующая инициализация на экране сохраняет продуктовую логику первого задания и ответы
- Демо и его управление сохранены

ESLint изменённых поведенческих файлов проходит. Браузерное подтверждение «один клик → первое задание» обязательно отдельно: unit-тест подтверждает вызов маршрутизатора, а не окончание загрузки страницы.
