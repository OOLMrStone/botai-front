# Походка лемура: найден точный референс

Дата: 29 сентября 2026

## Идентификация

Оба пользовательских бирюзовых кадра относятся к **Lemur by Frida Ek** для Animade. На [авторской странице Dribbble](https://dribbble.com/shots/3335578-Lemur) Frida описывает работу как небольшой walk cycle для своего проекта в Animade. [Публикация студии World Wildlife Day](https://dribbble.com/shots/3335612-World-Wildlife-Day) отдельно подтверждает автора Frida

Визуальное совпадение установлено по контактному листу скачанного GIF: та же бирюза, серый крупный таз, низкая маленькая голова с жёлтыми глазами, высокий кольчатый хвост, тонкая горизонтальная тень, два совпадающих поворота головы

## Реально скачано

Публичная копия [Make a GIF](https://makeagif.com/gif/lemur-by-frida-ek-AIavfU) содержит атрибуцию Frida Ek и ссылку-источник Tumblr. Сам GIF скачан оттуда, не напрямую из авторского Dribbble. Это важное различие между подтверждённым авторством и происхождением конкретных байтов

- `artifacts/lemur/references/walk/frida-ek-lemur.gif`: 500×500, 17 кадров, 1.12 секунды по ffprobe; не следует принимать формальный r_frame_rate=25 за постоянный фактический GIF framerate
- `artifacts/lemur/references/walk/frida-ek-lemur.mp4`: альтернативный воспроизводимый файл той же публикации
- `artifacts/lemur/references/walk/contact-sheet.png`: 9 выборочных фаз через 0.125 секунды, построены только для исследования поз
- `artifacts/lemur/references/walk/manifest.json`: точные URL файлов и публикаций

## Разбор фаз

Наблюдения по последовательности кадров, а не предположения из двух пользовательских PNG:

1. Это ходьба на месте с очевидным направлением вправо: лапы в опоре уходят назад, свободные выносятся вперёд
2. Передняя часть туловища очень низкая, крупный таз занимает верх силуэта. Комизм создаёт разница масс, а не быстрое покачивание всей картинки
3. Лапы подставляются под корпус; коленные/локтевые сгибы меняются в passing pose. Для нового rig недостаточно качать четыре прямые лапы
4. Голова проходит фронтальную фазу → профиль вправо → почти скрытое лицо → возвращение фронтально. Поворот короткий и вписан в цикл
5. Таз мягко перекатывается, при этом живот/белое пятно меняют видимую площадь. Это иллюзия объёма через перекрытия
6. Хвост остаётся вертикальным, его верхний крючок и изгиб слегка меняются с отставанием относительно таза. Не машет крупной дугой из стороны в сторону
7. Тень практически неподвижна; её роль - удержать весь смешной корпус на земле

## Как перенести в нашу модель

Сохранить механику четырёхлапой ходьбы, высокий зад, низкие передние лапы и направление вправо. Увеличить голову относительно этого рефа, чтобы не потерять идентичность нашего лемура. Маска, янтарные глаза и кончик хвоста должны совпадать с фронтальной моделью. У Frida конец хвоста светлый, у нашего по спецификации тёмный: механику заимствуем, палитру/раскраску сохраняем свою

Рабочая длительность нового цикла 1.1-1.4 секунды близка к найденной копии, но это рекомендация для тестирования, не норматив автора

## Проверка и ограничение

Файлы декодированы, метаданные прочитаны, последовательность фаз просмотрена на контактном листе. Повторный browser playback в этой подзадаче не выполнен: инструмент сообщил отсутствие доступного браузера, затем отсутствие Computer Use permissions. Это ограничение просмотра, не отсутствие motion-файла. Для окончательного motion QA открывать MP4/GIF в рабочем preview у основного агента
