## Покрытие

Проверены 139 символов через CoreText: русский алфавит в обоих регистрах, включая Ё/ё; английский алфавит в обоих регистрах; цифры и `+-=,.!?@_()`. Для каждого проверены ненулевой индекс глифа **и существующий непустой векторный контур**, а не только запись в таблице символов. Пропущенных или пустых глифов нет.

Это проверка содержимого файла при стандартном весе 400. Читаемость, размеры и поведение разных весов проверяются отдельно в браузере.
