# Настройка тренировки: отдельный экран

Карточка номера - вход в сценарий, а не аккордеон. Каталог сохраняет сетку и позицию прокрутки; карточки не растягиваются и не пересобирают соседей. Нажатие открывает `/training/setup` без таббара и затемнения.

Один каркас с настройкой квиза: крестик, заголовок, прокручиваемое содержимое, закреплённая кнопка запуска. Заголовок показывает предмет выбора: «Планиметрия», пояснение - номер задания. Далее «Что решаем»: «Все задачи» или одна тема; затем количество и сложность. Выбор темы не открывает ещё один слой. Запуск использует пересечение темы и сложности, выбранное количество и существующую историю. Нулевая подборка не запускается, причина видна рядом с действием.

Тексты и геометрия - из config. Общие SelectableCard, Button, RangeSlider и ScreenShell. Темы расположены в одну колонку: длинные названия не сталкиваются с индикаторами; длинное содержимое прокручивается, действие остаётся доступным. Закрытие и Escape возвращают в каталог. Настройка квиза сохраняет сложность/время, декоративное выражение под заголовком удаляется.

Вход - существующий ScreenTransition: короткие opacity/translate, без растягивания текста, изменения размеров карточек и слепков DOM. Reduced motion отключает этот переход. Удаляются старые reflow-хуки и состояние раскрытого номера.

Проверка: карточки 1/2 открывают одинаковый экран; выбор темы и количества меняет создаваемую сессию; закрытие не запускает тренировку; возврат из решения снова открывает настройки; темы без подходящих задач не позволяют запуск; 320/375/desktop, прокрутка, Escape, отсутствие формулы в квизе, lint и типы.

## Проверено

49 автоматических тестов проходят (включая 6 новых регрессий навигации/подборки), TypeScript без ошибок. В preview проверены обе карточки, тема «Треугольник» с запуском ровно 5 задач, Escape и возврат из тренировки, прокрутка 320×640, варианты 375×812, 430×900 и широкий экран. Квизы используют тот же вход без декоративной формулы. Наблюдался короткий вход через прозрачность/смещение; пересборки сетки больше нет. На коротких экранах нижняя часть настроек доступна прокруткой, CTA закреплён. Геометрические проверки не нашли нарушений; консоль без ошибок.

Скриншоты: `artifacts/design-system/training-setup-430.png`, `training-setup-375.png`, `quiz-setup-clean-375.png`. Физическое устройство и системный reduced motion в этой проверке не эмулировались; используется существующий motion-safe переход.
